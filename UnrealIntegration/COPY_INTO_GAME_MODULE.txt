---

1) Merge UnrealStarter/BasketballGame/Config/DefaultEngine.pixelstreaming2.snippet.ini into your live project's Config/DefaultEngine.ini.

2) Copy *.h / *.cpp from UnrealIntegration/Source/FinalEvolutionLab/ into your game's Source/FinalEvolutionLab/ folder (same names), or use ./prepare_fel_bridge.sh --copy-sources.

   Deep links (FELBridge native shell ↔ UE map travel):
     • Merge UnrealIntegration/Config/DefaultEngine.FEL_iOS_URL_scheme.snippet.ini into DefaultEngine.ini (registers **finalevolution://**).
     • UFELDeepLinkSubsystem parses URLs like `finalevolution://launch?map=Zen_Dojo&mode=karate_h2h`, opens `/Game/FEL/Maps/<Venue>`,
       maps **brain_brawl** → **Neuro_Arena**, then UFELBridgeSubsystem sends JSON `{ "type":"map_loaded", ... }` on the **same** FELBridge WebSocket as other events (not Pixel Streaming port 8888 — that remains signaling for streaming).

3) FinalEvolutionLab.Build.cs — add to PrivateDependencyModuleNames:
     "WebSockets",
     "Json",

4) Enable WebSockets plugin in .uproject if not already (Editor → Plugins → WebSockets).

5) Configure URL (pick one): DefaultGame.ini [FELBridge] GameWebSocketUrl, FEL_GAME_WS_URL env, or Blueprint/C++:

     UFELBridgeSubsystem* B = GameInstance->GetSubsystem<UFELBridgeSubsystem>();
     // Optional if already set via ini/env:
     B->SetGameWebSocketUrl(TEXT("wss://your-host/ws/game/YOUR_ROOM_ID"));
     B->SetFocusKeepaliveEnabled(true, 0.5f);
     // ... end of match:
     B->SendMatchScoreToWebSocket(TeamA, TeamB, TEXT("{}"));

   Bridge behavior (current integration sources):
     • Outbound JSON is queued while the socket is connecting/disconnected (bounded queue); flushed on connect.
     • Inbound UTF-8 text frames: bind Blueprint event OnRawMessage (or parse JSON in C++).
     • Auto-reconnect: DefaultGame.ini [FELBridge] bAutoReconnect / ReconnectDelaySeconds / MaxReconnectAttempts.

   Pixel Streaming 2 alternative (iframe focus): add UFELFocusKeepaliveTickComponent to your persistent actor,
   bind OnKeepalive in Blueprint to PixelStreaming2 Streamer Component → SendAllPlayersMessage
   ("ApplicationEvent", "{\"action\":\"focus_keepalive\"}") per E3DS docs.

6) Copy FEL_VenueRegistry.production.json beside Config or load from your analytics bridge.

7) Win64 cook (requires Windows target on Mac): ./fel_ue5_win64_cook_only.sh

8) Linux E3DS package (no Windows needed; requires Linux target + cross-compile toolchain on Mac):
     ./fel_ue5_eagle3d_linux_package.sh
   Output: artifacts/Linux/FEL_UE5_E3DS_Linux_Package.zip — WebSockets bridge is OS-agnostic (Linux Shipping OK).
