# iOS + Unreal shipping pipe

## Scripts (this repo)

- **`fel_ue5_ios_shipping_package.sh`**
  - GenerateProjectFiles-friendly prep, RunUAT **BuildCookRun** (platform iOS), archive dir, **verify** staged `.app` plist + cooked payload hints.
  - **Descriptor-safe repack:** ZIP from promoted cooked `.app` → `Binaries/IOS/FinalEvolutionLab.ipa` when valid (see script comments).
  - **`--export-ipa`:** `xcodebuild` archive + `-exportArchive` using **`infra/ue5_config/ExportOptions.plist`** (`method`: **app-store**) for **TestFlight / App Store Connect** style IPA output—not alternate store flows.

## Config fragments

- **`UnrealIntegration/Config/DefaultEngine.FEL_iOS_URL_scheme.snippet.ini`** — merge into UE **`DefaultEngine.ini`**: `AdditionalPlistData` for **`finalevolution://`**, camera/health/bluetooth usage strings (single string constraint).
- **`infra/ue5_config/DefaultGame.ini`** — reference **packaging / maps / staging** defaults.

## On-disk UE project (usually not fully in Git)

The **authoritative** iOS Xcode workspace generated by UE is typically:

`~/Developer/FinalEvolutionLab57/FinalEvolutionLab (IOS).xcworkspace`

after GenerateProjectFiles / RunUAT. Automation must reference **`UPROJECT`** explicitly when not using defaults inside the shell script.

## Success criteria for device / ASC

1. Staged `.app` contains **cooked payload** (`cookeddata/` and/or `.pak`).
2. Root **`Info.plist`** has **`CFBundleIdentifier`** and privacy keys matching APIs used.
3. **Signing:** Team + capabilities (e.g. HealthKit) match **App ID** in Apple Developer + ASC record.
